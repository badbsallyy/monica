# Quick Start Guide

Get started with Monica in 3 minutes!

## Installation (1 minute)

1. **Download**: Clone or download this repository
2. **Open Extensions**: Go to `chrome://extensions/`
3. **Developer Mode**: Toggle ON in top-right
4. **Load Extension**: Click "Load unpacked" → Select `monica` folder
5. **Done!** You'll see the Monica icon in your toolbar

## First Steps (2 minutes)

### Save Your First Link

**Option A: Current Page**
1. Click the Monica icon 🎯
2. Click "Save Current Page" button
3. ✓ Done! Your page is saved

**Option B: Right-Click Menu**
1. Right-click anywhere on a webpage
2. Select "Save to Monica"
3. ✓ Done!

**Option C: Manual Entry**
1. Click the Monica icon
2. Click "Add Link" tab
3. Enter URL and title
4. Click "Add Link"

### View Your Links

1. Click the Monica icon
2. See all your saved links in "All Links" tab
3. Click any link to see details

### Search Your Links

1. Type in the search box at the top
2. Press Enter or click "Search"
3. See filtered results instantly

### Organize with Tags

When adding a link:
1. Enter tags in the "Tags" field (comma-separated)
2. Example: `work, important, javascript`
3. Click "Tags" tab to browse by tag

## Essential Features

### 📋 View All Links
- Click Monica icon → "All Links" tab
- Click any link to see full details
- Click link URL to open in new tab

### 🔍 Search
- Fast search across titles, URLs, descriptions, and tags
- Type your query and press Enter
- Results update instantly

### 🏷️ Tags
- Add multiple tags to each link
- Browse all tags in "Tags" tab
- Click a tag to see all related links

### 💾 Export
- Click "Export" button at bottom
- Downloads all your links as JSON
- Keep backups of your data!

### 🗑️ Delete
- Click a link to open details
- Click "Delete" button
- Confirm deletion

## Pro Tips

1. **Use Tags Wisely**
   - Create categories: `work`, `personal`, `learning`
   - Use descriptive tags: `javascript`, `python`, `tutorial`
   - Be consistent with tag names

2. **Right-Click Shortcut**
   - Right-click any link → "Save to Monica"
   - Fastest way to save links while browsing

3. **Search Everything**
   - Search works on all fields
   - Try partial matches: "java" finds "javascript"
   - Case-insensitive search

4. **Regular Exports**
   - Export your links weekly
   - Keep backups before major updates
   - Easy to restore if needed

5. **Organize as You Go**
   - Add tags when saving links
   - Better than organizing later
   - Saves time in the long run
